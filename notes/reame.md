### Instalação do Yarn
Instalar o Corepack, uma ferramenta intermediária que permitirá configurar a versão do gerenciador de pacotes por projeto:
```bash
npm install -g corepack
```
Habilitar o Corepack:
```bash
corepack enable
```
Instalar o Yarn:
```bash
corepack enable yarn
```
## Instalação do Node.js
Acesse o site https://nodejs.org/ e baixe a versão LTS.

## Criando um projeto
Acesse o terminal no diretório onde deseja criar o projeto e execute o comando:
```bash
npx create-react-app primeiro-app
```

## Executando o projeto
cd primeiro-app
npm start
